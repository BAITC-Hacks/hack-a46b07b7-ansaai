# Для следующего AI-агента

## Задача

Перенести эту версию в существующий приватный репозиторий `BAITC-Hacks/hack-a46b07b7-ansaai`, проверить изменения, сделать commit/push и развернуть приложение при наличии доступа к хостингу. Сохранить изменения других участников.

## Содержимое архива

Каталог `taskready-ai/` — корень проекта, его содержимое нужно объединить с рабочей копией репозитория. Это архив без `.git`, а не Git-клон. Не создавать вложенный второй проект внутри существующего репозитория. Сначала изучить текущий `git status`, ветку и инструкции организаторов.

## Реализовано

- Светлая рубиновая тема с золотыми акцентами, плотная типографика, глянцевые 3D-бейджи, знаки прогресса из реальных событий, поиск/фильтры/сортировка, адаптация для телефона.
- FastAPI + отдельные таблицы SQLite: users, sessions, tasks, offers, ledger, audit, rate_limits.
- Пароли PBKDF2, HttpOnly/SameSite cookie, CSRF, проверки роли/владельца на сервере.
- Создание и редактирование задачи, защита от повторной публикации и конфликтов версий.
- Отклик один раз на пару задача/команда; ручное принятие/отклонение; +5 за принятие, +10 за единственное подтверждение прогресса с описанием результата.
- OpenAI Responses + строгая схема + проверка дословных источников. Ошибка провайдера не скрывается локальным ответом.
- Общая рубрика конкретности для Python и JS. Правила хранятся в `public/rubric.json`.
- Автономное HTML-демо с минимум 5 карточками, 5 профилями команд и 5 предложениями; ссылка на прототип обязательна. Есть инструкция защиты, сценарий и набор из 10 AI-кейсов.

## Обязательные проверки

```bash
python -m pip install -r requirements-dev.txt
python scripts/build_demo.py
node --check app.js
python -m py_compile backend/main.py backend/ai.py backend/scoring.py
python -m pytest -q
python scripts/evaluate_ai.py
```

Браузерный тест: `npm install --prefix /tmp/taskready-tests playwright`, установить совместимый Chromium, затем `NODE_PATH=/tmp/taskready-tests/node_modules node tests/e2e.cjs`. При уже установленном браузере задайте `CHROMIUM_PATH`; для Python задайте `TASKREADY_PYTHON` (по умолчанию `python3`). Скрипт сам запускает тестовый сервер и использует отдельную временную БД.

## Не завершено из-за внешнего доступа

1. **Живой запрос LLM**: API-ключа нет. Контракт и ошибочные ответы проверены с тестовым провайдером; не утверждать, что боевой AI проверен. Добавить ключ в secret/env хостинга, затем выполнить `python scripts/evaluate_ai.py --live`. Это делает платные API-запросы.
2. **Публичное демо**: статическая версия опубликована на [https://ansaai.netlify.app](https://ansaai.netlify.app); изменения сохраняются локально у посетителя. Для серверной версии с аккаунтами следовать `DEPLOYMENT.md`: Render Blueprint использует платный `starter` и постоянный диск, стоимость нужно проверить до создания ресурса.
3. **Docker**: Engine недоступен в исходной среде. Собрать и проверить образ там, где он установлен.

Не запрашивать приватный SSH-ключ/API-ключ в переписке и не включать их в файлы репозитория. Не копировать `.env`, SQLite, тестовые аккаунты, cache, screenshots и runtime-файлы в коммит.

## Совместимость

Новая БД — `data/taskready-v3.sqlite3`, прежняя `taskready.sqlite3` не перезаписывается. Старое общее состояние автоматически не импортируется: у него не было реальных владельцев/аккаунтов. При необходимости переноса сначала сопоставить задачи с владельцами и сделать backup. `public/` генерируется из корневых frontend-файлов; сначала редактировать `app.js`/`styles.css`, потом выполнить build.

Текущая согласованная гамма — светлая, с рубиново-красным и золотым акцентами; при дальнейших изменениях сохранить её и насыщенную типографику.
