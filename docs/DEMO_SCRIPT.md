# Демонстрация для жюри

## Подготовка

Сервер: создать аккаунт бизнеса и аккаунт команды в двух разных профилях браузера. Ключ хранить в серверном окружении. Если ключа нет, показывать локальный режим с его явной отметкой. Автономный `TaskReady-demo.html` уже содержит учебные данные и демо-переключатель ролей.

## Сценарий

1. Обзор: показать поиск и фильтры. Нажать «Новая задача» → «Пример для демо».
2. Исходная проблема: менеджеры вручную переносят заявки из почты в таблицу, теряют обращения и тратят 4 часа в неделю.
3. Нажать «Уточнить задачу». Ответить на вопросы:
   - Данные: доступна CSV-выгрузка, 150 заявок за месяц и 20 обезличенных примеров.
   - Результат: прототип импорта и маршрутизации заявок в единый реестр.
   - Успех: не менее 80% заявок без ручного копирования, экономия 4 часов в неделю.
   - Ограничения: 2 недели, без доступа к продакшену.
   - Пользователи: менеджеры отдела продаж, ежедневно обрабатывающие заявки.
   - Связь: руководитель отдела, еженедельный созвон по пятницам.
4. Собрать карточку. На шаге редактирования дополнить оставшиеся поля и показать причины баллов Readiness DNA.
5. Подтвердить сведения и опубликовать.
6. Команда открывает новую задачу. Идея: «Импортируем CSV и распределяем заявки по менеджерам». План: «Импорт, реестр, журнал ошибок; проверка на 20 примерах». Срок: 10 дней. Добавить ссылку на прототип, например `https://example.com/prototype`.
7. Бизнес открывает «Отклики», выбирает команду, затем подтверждает прогресс: «Проверили импорт на 20 примерах, все поля сохранены».
8. Показать подтверждение и итоговые баллы команды (+5 за старт, +10 за результат). Кнопка повторного подтверждения отсутствует.
9. Открыть аналитику и экспортировать данные.

## Резервная запись

`TaskReady-walkthrough.mp4` — запись автономного сценария с пояснениями на экране, без аудио. Реальный вызов LLM в ней не демонстрируется. Использовать текст `PITCH.md` для живого выступления. Запись не заменяет проверку опубликованного сервера.

## Перед выходом

Проверить вход обоих аккаунтов, срок действия AI-ключа, доступность `/api/health`, сохранность задач после перезагрузки. Держать HTML и MP4 локально на компьютере для резервного показа.
