# TaskReady AI

TaskReady AI — автономный MVP для HackAlem AI. Сервис превращает короткое и неструктурированное описание бизнес-потребности в редактируемую карточку задачи, оценивает её готовность и публикует в открытом каталоге для студенческих команд.

## Почему это решение

- AI находит пробелы и задаёт минимум 3 контекстных вопроса.
- AI не добавляет факты, которых не сообщил бизнес.
- Бизнес редактирует и подтверждает карточку до публикации.
- Рейтинг 0–100 прозрачно показывает готовность задачи.
- Низкий рейтинг не скрывает задачу и не блокирует отклики.
- Команды подают предложения, а бизнес вручную выбирает одну, несколько или ни одной команды.
- Есть локальный demo-режим без API-ключей и сервера.

## Архитектура

Проект переведён на Python-стек с сохранением standalone-режима:

- `backend/main.py` — FastAPI API, scoring service, AI fallback и раздача frontend.
- `backend/requirements.txt` — зависимости Python.
- `index.html`, `styles.css`, `app.js` — Readiness OS frontend.
- `data/taskready.sqlite3` — SQLite-хранилище состояния демо.
- `Dockerfile` и `docker-compose.yml` — воспроизводимый запуск.

Frontend автоматически использует FastAPI, если открыт через `http://localhost:8000`. При открытии одного HTML-файла продолжает работать через `localStorage`, поэтому демо можно проверять без установки Python.

Основные backend endpoints:

```text
GET  /api/health
GET  /api/state
PUT  /api/state
POST /api/tasks/analyze
POST /api/tasks/score
GET  /api/tasks
POST /api/tasks
GET  /api/offers
POST /api/offers
POST /api/offers/{id}/decision
```

AI-функция сейчас работает в безопасном локальном fallback-режиме: анализирует текст, находит смысловые пробелы и возвращает минимум 3 структурированных вопроса. Контракт подготовлен для подключения внешней LLM без изменения интерфейса.

## Запуск

### Рекомендуемый запуск через Docker

```bash
cp .env.example .env
docker compose up --build
```

Открыть: <http://localhost:8000>

### Локальный Python-запуск

Требуется Python 3.10+.

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r backend/requirements.txt
uvicorn backend.main:app --reload --port 8000
```

Открыть: <http://localhost:8000>

API-документация: <http://localhost:8000/docs>

### Standalone HTML

Для быстрого просмотра без backend можно открыть `index.html` или `taskready-ai-demo.html`. В этом режиме используется `localStorage`.

## Зависимости

- Python 3.10+
- FastAPI
- Uvicorn
- SQLite входит в Python
- Современный браузер с поддержкой ES2020

## Параметры окружения

Скопируйте `.env.example` в `.env`. Все параметры опциональны:

```text
TASKREADY_AI_PROVIDER=local
TASKREADY_AI_MODEL=
TASKREADY_AI_API_KEY=
```

Без ключа система использует локальный fallback и запускается автономно.

## Проверка основного сценария

1. Открыть приложение.
2. Нажать **Создать задачу**.
3. Ввести слабое описание, например:

   > Менеджеры вручную переносят заявки из почты в таблицу, из-за этого часть обращений теряется.

4. Нажать **Проанализировать черновик**.
5. Ответить минимум на 3 вопроса AI.
6. Проверить редактируемую карточку и блок **Readiness DNA**.
7. Убедиться, что рейтинг меняется после заполнения полей.
8. Поставить подтверждение бизнеса и нажать **Подтвердить и опубликовать**.
9. Открыть **Каталог задач** и проверить сортировку, отраслевые фильтры и уровни готовности.
10. Переключиться в режим **Команда**.
11. Открыть карточку задачи и отправить предложение с идеей и планом.
12. Переключиться в режим **Бизнес** → **Отклики**.
13. Выбрать или отклонить предложение вручную.
14. Для выбранного отклика нажать **Подтвердить прогресс**.

## Формула рейтинга

| Критерий | Вес |
| --- | ---: |
| Контекст и потребность | 20 |
| Данные и материалы | 20 |
| Ожидаемый результат | 15 |
| Критерии успеха | 15 |
| Ограничения | 10 |
| Пользователи | 10 |
| Связь с бизнесом | 10 |
| **Всего** | **100** |

Для каждого критерия используется уровень заполненности: 0 — отсутствует, 0.5 — частично или слишком общо, 1 — конкретно заполнено. Баллы начисляются только за данные в подтверждаемой карточке.

## Защита от выдуманных фактов

В продакшен-версии AI-ответ должен проходить JSON Schema/Pydantic-валидацию. Каждое значение карточки желательно хранить вместе с источником: исходный текст, ответ бизнеса или ручная правка. До публикации обязательна ручная проверка.

## Демо-данные

При первом запуске доступны 4 задачи, 3 команды и 3 отклика. Кнопка **Экспорт demo JSON** в разделе аналитики выгружает текущее состояние.

## Визуальная концепция

Интерфейс выполнен в стиле Readiness OS: тёмный рабочий canvas, светлые функциональные панели, крупный Readiness Score, AI Step, Readiness DNA, Catalog, Decision Room и Analytics. Все панели на dashboard интерактивны и ведут в соответствующие рабочие сценарии.
